Vault market reader

Map and verify visible prices. The extension never submits game orders or clicks trade controls.

Checking the game tab...

1. Local session key

Run node vault/bridge/server.mjs. Paste the printed 36-character key here and into your Vault panel.

Checking bridge...

2. Map and verify actual values

Click Pick then click the relevant price in the game. Click Check to preview the number extracted. If the element contains several numbers, enter Number # (1 = first). If a CSS selector matches several rows, enter Element #.

Optional sizes, positions and working orders

For numbers in an element's attribute, enter its name in Attribute, such as aria-label or data-price. Leave both index fields empty when only one value exists.

3. Start read-only capture

Review preview results before starting. Canvas-only graphics, closed shadow roots, and inaccessible frames need a different adapter.
