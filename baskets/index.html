Set up automatic read-only capture

1. Run node baskets/bridge/server.mjs from your repository root. Copy the 36-character session key printed in your terminal.

2. Open chrome://extensions, enable Developer mode, and select Load unpacked. Choose the baskets/bridge/extension folder.

3. Open the actual Baskets trading tab. Open the extension, enter the key, then choose Pick for each GRID/CURE/SAFE bid and ask. Click the displayed value on the game page. Start capture.

4. In this local Baskets panel, paste the same key and click Connect. Current mapped prices and optional inventory refresh automatically. You can still record event-bot volume manually.

The game interface is not yet available for us to inspect, so CSS field mapping must be confirmed on the actual page. If the interface renders values only on a canvas, this DOM adapter cannot read them without further work.

Flow classifications and input guide

Confirmed event: Add signed volume only if you can reliably identify the event bot. This volume changes the theoretical settlement directly.

Suspected event: Use for a directional burst that may be event-bot flow. It contributes only after the confidence discount in Strategy settings.

Public tape: Use for buy- or sell-initiated trades that could come from customers, makers or other teams. It informs rival behavior only. It never moves modeled settlement.

Positive values mean buys, negative values mean sells. All buttons add volume for the selected basket. Undo reverses your latest entry. Do not add the same trade to more than one flow category.

Inventory and PnL guide

Position is your signed filled inventory. Positive is long and negative is short. This panel increases or decreases position when you log a real fill.

Working buy/sell shares are outstanding orders that could still fill. Enter total shares per side, including multiple orders. Edit them after fills or cancellations.

Filled shares and price record executed trades, not submitted but unfilled orders. If you manually overwrite position, this panel cannot reconstruct historical cash PnL and hides that estimate.
