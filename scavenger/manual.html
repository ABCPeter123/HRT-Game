AT A GLANCE

One-screen workflow

Solo play, five rounds: enter the announced percentile → record your purchased samples → enter one bid in each of the three auction phases → record your actual rank and payout → submit the final guess. The model updates after every result. The only submission that counts is the one made in the official competition interface.

This game is scored individually. Do not divide live decision-making, reveal private sample data, or coordinate bids with another competitor unless the organizer explicitly permits it. The partner workflow below is for practice or an authorized non-playing helper, not an assumption that collaboration is allowed.
BEFORE ROUND 1

Set up your desk

  1. Open the Scavenger panel. From the competition homepage select 01. Scavenger. Keep the real game in a second window or browser tab. Your browser stores panel records on this device.
  2. Select the correct round. Use the top ROUND buttons. You should begin on Round 1. The phase buttons underneath show the information window, three auctions, and final guess.
  3. Arrange the screens. Put the official game on one side and the panel on the other. Use the actual game countdown as the deadline; the panel's Start and Reset timer are reference clocks.
  4. Leave model learning on unless testing a baseline. The Prior rounds ON toggle in Cross-round learning lets verified earlier outcomes inform later recommendations. This is statistical guidance, not a guarantee.
PARTNER PRACTICE

How to work beside another person

YOU · OFFICIAL PLAYER

Own every game action

Read the announced percentile, decide sample count, enter official bids, check results, and submit the final guess. If live assistance is not allowed, operate the panel yourself.

AUTHORIZED HELPER / PRACTICE ONLY

Keep records and time

For rehearsal or with explicit permission, read the reference timer aloud and enter your supplied observations into the panel. Never send bids or receive private data without permission.

Safe rehearsal: one person impersonates the game screen and announces percentile, samples, ranks, and payouts. The other operates the panel. Swap roles after a full mock round. On competition day, default to solo participation unless officials approve otherwise.

EACH ROUND

Exact buttons and data flow

  1. Information stage: 60 seconds. In the Information stage input panel, type the announced pool percentile. Read the large RECOMMENDED ACTION sample-count suggestion. Choose how many samples to actually buy in the game, then enter that number and paste/type the returned sample observations in LIVE INPUT. Click Use recommendation only if you want to copy the suggested number into a local field. It does not purchase samples.
  2. Bid 1: 60 seconds. Switch to Auction 1 using the phase navigation. Read the suggested non-negative integer bid. Enter and submit it in the official game before the countdown ends. If available, click Fill bid field or Use recommendation to populate the panel's local bid entry. Make sure the panel records the bid you actually sent, even if it differs from the suggestion.
  3. Results window: 30 seconds. When the exchange announces your bid rank and points paid, enter both into the round input area. Rank 1 is the lowest bid; the highest rank is the highest bidder. Check your entries in Your progress. The engine uses ranks to update its opponent-bidding assumptions.
  4. Repeat for Auctions 2 and 3. Follow the phase buttons for the next bid. Use the updated recommendation, but submit in the game yourself. Log the actual rank and points after each auction. Auction 3 points count twice toward the round score.
  5. Final guess: 90 seconds. Select Final guess, review the pool estimate and integer guess, then submit it in the official game. Record the real pool once it is revealed; this helps subsequent rounds. The guessing bonus falls as absolute error grows.
  6. Move to the next round. Use the next numbered round button. Each round keeps its own inputs. Your opponents may change, so don't treat previous ranks as if the same room persisted.
HOW TO GET MORE VALUE

Practical decision checklist

  • Purchase samples selectively. Sampling has a real deduction, proportional to the pool size times √n/12. More observations can improve estimation, but buying many blindly can lose points. The sample suggestion is a heuristic; use the displayed uncertainty and earlier rounds as context.
  • Recheck the number that matters. The percentile alone does not reveal the pool size. Never treat a model estimate as an observed value. Enter all purchased sample outcomes accurately.
  • Respect auction asymmetry. The three lowest bids get capped payouts before the highest bid's residual payoff and overbid penalty. Other bidders receive zero. A very large bid can be dangerous if you end up highest and the remaining pool is small.
  • Prioritize Auction 3 execution. Since that auction's result is doubled, missing its deadline is more costly than missing the same payout in Auction 1.
  • Use Opponent counterplay carefully. It adapts to observed ranks, not other players' hidden bids. Don't assume it knows opponents' exact willingness to pay.
Example report in a practice run: “Auction 2 submitted: 84. Result: rank 3 of 6, payout 84. Recording it now.” The helper should repeat the number and rank back before saving.
TROUBLESHOOT

Avoid expensive input mistakes

ProblemAction
Countdown mismatchFollow the official countdown. The local Reset only affects the local timer.
Recommendation doesn't match your submitted bidRecord the actual bid. Never change the official number to match the tool.
Bid rank seems wrongRemember rank 1 means lowest bidder, not first place. Check room size before entering.
No sample purchaseEnter zero purchased samples. Do not invent sample values or a precise pool size.
Need to restart from Round 1Use Reset entire game in the top bar; confirm deletion. This erases all five rounds and learned history for Scavenger only.
Switching devicesLocal saved records do not synchronize. Keep the game and panel on the same device for the full session.
BEFORE YOU ADVANCE

Round-completion checklist

  • Official Auction 1, 2, and 3 submissions were made before their deadlines.
  • All three actual bids, ranks, and payouts are recorded, including any zero-point outcome.
  • Final integer guess was submitted in the real game, not only typed into the panel.
  • True pool size, if shown, is recorded so the model can learn for later rounds.
  • Correct next round is selected, with a fresh room and official timer.
